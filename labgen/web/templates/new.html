Как работает агент

Граф LangGraph — шаги видны на следующей странице в реальном времени.

  1. План — режим и образец из каталога того же уровня
  2. Генерация — LLM пишет условие, шаблон, эталон, тесты, мутанты
  3. Проверка — эталон проходит тесты, шаблон нет, тесты ловят мутантов
  4. Исправление — при ошибках LLM чинит работу по замечаниям (до 3 попыток)
  5. Рецензия — замечания для преподавателя, без баллов
  6. Симуляция — LLM-студенты решают задание (по желанию)
