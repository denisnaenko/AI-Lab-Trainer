# Агент с инструментами

Агент — это цикл: модель получает историю сообщений и список инструментов, либо отвечает
текстом, либо просит вызвать инструмент. Программа выполняет инструмент, добавляет его
результат в историю и снова обращается к модели. В этой работе вы реализуете такой цикл
и простой инструмент-калькулятор.

Модель в тестах заменена на `FakeLLM`: она возвращает заранее заданные ответы, поэтому
работа не требует API-ключа, а проверка детерминирована.
